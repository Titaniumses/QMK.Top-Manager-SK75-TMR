# QMK.Top Manager v1.0.1

This release improves day-to-day reliability and removes unwanted online behavior.

## What changed

- Fixed profile switching in wireless mode.
- The app now starts offline by default and no longer tries to reach external services on launch.
- The Windows build now includes its desktop runtime, so first launch does not depend on downloading components.
- The HID sniffer is now opt-in and stays disabled during normal use.
- Version updated to `1.0.1.0`.

## For you

Use the attached `dist/QMK.Top Manager.exe` with this release.
